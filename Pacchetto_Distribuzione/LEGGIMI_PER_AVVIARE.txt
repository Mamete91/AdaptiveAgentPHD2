=== PHD2 Adaptive Guiding Agent v1.1 ===

PREREQUISITI
------------
1. Assicurati di aver aperto PHD2.
2. In PHD2 vai in Strumenti -> Abilita Server.
3. (Opzionale) Esegui 'Diagnostica_Connessione.exe' per verificare la connessione
   (devono comparire tre luci verdi nel log).

DASHBOARD
---------
Apri il browser e vai su: http://localhost:8080

CONFIGURAZIONE
--------------
Ogni file config_*.toml corrisponde a un setup. I parametri principali:
  dry_run = true    -> modalita' analisi (nessun comando inviato a PHD2)
  dry_run = false   -> modalita' LIVE (l'agente modifica parametri di guida)

  NOTA: tutti i config_*.toml hanno dry_run=false e exposure_dynamic.enabled=true.
  Il config.toml di default (fallback) ha dry_run=true ed e' solo per emergenze.

FIREWALL
--------
Se la dashboard non e' raggiungibile da altri dispositivi sulla rete locale,
eseguire 'Sblocca_Firewall_8080.bat' come Amministratore (una sola volta).
